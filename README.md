# NGP SS!2 커스텀 플레이어(Android)
### 한패 / 가상 랭크매치 / SP키 / 컬러 추가 / 스테이지 추가

안녕하세요. 네오지오 포켓 컬러용 **사무라이 쇼다운! 2**를 안드로이드에서 즐길 수 있도록 만든 커스텀 플레이어, **잔심**을 소개합니다.

사무라이 쇼다운! 2는 작은 도트 캐릭터로 칼을 겨루는 대전 격투게임입니다. 상대와 거리를 재고, 공격을 막거나 피한 뒤 반격하는 공방을 즐길 수 있습니다. 같은 캐릭터도 **수라·나찰**에 따라 기술 구성이 달라지고, 플레이하며 얻은 **카드**로 능력과 기술에 변화를 줄 수 있습니다.

잔심은 이 원작에 **한글패치, 방향별 SP 기술, CPU 가상 랭크매치, 캐릭터 컬러와 추가 스테이지**를 더한 팬 프로젝트입니다. 휴대폰에서 조작하기 편하도록 버튼과 게임 화면의 위치·크기도 직접 바꿀 수 있게 했습니다.

## 한글로 플레이하기

지원되는 순정 ROM을 가져오면 한글패치를 적용해 플레이할 수 있습니다. 원본 ROM 파일은 그대로 보존합니다. 가져온 게임은 인터넷 연결 없이 즐길 수 있습니다.

싱글로 원작의 진행과 카드 수집을 즐기거나, 연습에서 기술을 익히고, 무한 대전과 가상 리그로 계속 대전할 수 있습니다. **수라·나찰과 카드 시스템은 원작에 있던 요소**이며, 잔심의 조작 보조와 가상 리그를 함께 이용할 수 있습니다.

## 방향 + SP로 쓰는 기술

자주 쓰는 기술을 방향별로 배치하고, **방향과 SP 버튼**을 눌러 사용합니다. 복잡한 커맨드 입력을 줄여 터치 화면에서도 필요한 기술을 꺼내기 쉽게 했습니다.

화면의 **기술배치**를 누르면 배정된 기술을 확인하고 바꿀 수 있습니다. 대전 중에는 현재 캐릭터와 수라·나찰에 맞는 배치를 열고, 대전 밖에서는 편집할 대상을 직접 고릅니다. 카드나 게이지처럼 기술을 쓰는 데 필요한 조건은 그대로 적용됩니다.

## CPU와 이어가는 가상 랭크매치

가상 리그에서는 ID와 계급을 가진 CPU 상대와 겨룹니다. 배치 경기를 거쳐 점수를 쌓고, 승급과 강등을 오가며 다음 상대를 만납니다. 대전 전에는 서로의 캐릭터와 계급을 확인하고 무대도 고를 수 있습니다.

한 캐릭터로 계급을 올려 보거나 다른 캐릭터와 카드 구성으로 도전할 수 있고, 중간에 저장하고 나갔다가 이어서 플레이할 수도 있습니다.

**상대는 CPU입니다. 실제 사람과 접속하는 온라인 대전은 아닙니다.**

## 캐릭터 컬러와 추가 스테이지 20종

캐릭터 선택 화면에서 **OPTION**으로 컬러를 바꾸고, 베기색도 취향에 맞게 고를 수 있습니다. 익숙한 캐릭터를 다른 색 조합으로 플레이해 보세요.

원작 무대에 더해 **20종의 추가 스테이지**를 담았습니다. 대전할 무대를 직접 고를 수 있으며, 경기가 시작될 때 무대의 그림과 이름을 보여 주는 도입 연출도 있습니다.

## 손에 맞추는 화면과 버튼

게임 화면과 터치 버튼의 **위치·크기**를 조절할 수 있습니다. 자주 누르는 버튼을 가까이 두거나, 화면을 보기 편한 위치로 옮겨 사용할 수 있습니다.

화면 필터와 움직임 보간도 선택할 수 있습니다. 기술을 어느 방향에 배정할지 정하는 **기술배치**와, 화면 위 버튼을 옮기는 **조작 배치**를 각각 설정할 수 있습니다.
